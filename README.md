# AI Quality Engineering Workbench

An AI Quality Engineering portfolio project focused on testing and evaluating:

- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Agentic AI workflows
- AI application security

## Technology Stack

Python, Pytest, DeepEval, Ragas, ChromaDB,
Streamlit, Plotly and GitHub Actions.

## Project Status

Phase 1 - Environment and project foundation.

## Project Objective

Build a reusable framework to evaluate AI application
quality, reliability, safety and functional behaviour.

## Important

This is an actively developing portfolio project.
Implementation results and performance metrics will
be documented after actual execution.
